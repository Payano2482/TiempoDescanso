# TiempoDescanso

Aplicación para controlar el tiempo de descanso de empleados.

## Características

- Control de tiempo de descanso
- Notificaciones sonoras
- Almacenamiento local de datos
- Interfaz intuitiva

## Tecnologías

- Angular
- Ionic
- TypeScript
- SCSS

## Instalación

```bash
npm install
```

## Desarrollo

```bash
ng serve
```

## Construcción

```bash
ng build --configuration production
```

## Despliegue

La aplicación está desplegada en Netlify y puede ser accedida a través de un enlace web.
